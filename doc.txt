# 9C. Os meus pedidos — Cliente

**Ficheiro:** `lib/features/client/presentation/client_jobs_screen.dart`

**Dependências novas:** nenhuma.

Esta versão cobre **Ativos**, **Histórico**, loading, erro e os dois vazios do mockup. Mantém o sistema definitivo de estados: o badge principal recebe sempre `AppStatusPresentation` do `JobStatus`, e uma remarcação usa uma segunda `AppStatusPresentation` proveniente de `RescheduleStatus`.

import 'package:flutter/material.dart';
import 'package:riverpod/riverpod.dart' show AsyncValue;

import '../../../core/theme/app_colors.dart';
import '../../../core/theme/app_radius.dart';
import '../../../core/theme/app_spacing.dart';
import '../../../core/theme/app_status_color.dart';
import '../../../core/theme/app_status_presenters.dart';
import '../../../core/widgets/app_motion.dart';
import '../../../core/widgets/app_status_badge.dart';
import '../../../core/widgets/primary_action_button.dart';

enum ClientJobsTab {
  active,
  history,
}

class ClientJobsViewData {
  const ClientJobsViewData({
    required this.activeTabLabel,
    required this.historyTabLabel,
    required this.activeJobs,
    required this.historyJobs,
  });

  /// Já formatado pela integração.
  /// Ex.: "Ativos · 3".
  final String activeTabLabel;

  final String historyTabLabel;

  final List<ClientJobListItemViewData> activeJobs;
  final List<ClientJobListItemViewData> historyJobs;
}

class ClientJobListItemViewData {
  const ClientJobListItemViewData({
    required this.jobId,
    required this.title,
    required this.locationLabel,
    required this.dateLabel,
    required this.serviceIcon,
    required this.statusPresentation,
    this.secondaryStatusPresentation,
  });

  final String jobId;
  final String title;

  /// Morada/localidade já preparada pela integração.
  final String locationLabel;

  /// Data, preferência ou DateMode já convertido em texto.
  /// O widget não assume a existência de hora.
  final String dateLabel;

  final IconData serviceIcon;

  /// Presenter oficial de JobStatus.
  final AppStatusPresentation statusPresentation;

  /// Ex.: RescheduleStatus.pending.
  final AppStatusPresentation? secondaryStatusPresentation;
}

class ClientJobsScreen extends StatefulWidget {
  const ClientJobsScreen({
    super.key,
    required this.dataAsync,
    required this.onOpenJob,
    required this.onCreateJob,
    this.initialTab = ClientJobsTab.active,
    this.onTabChanged,
    this.onRetry,
  });

  final AsyncValue<ClientJobsViewData> dataAsync;

  final ClientJobsTab initialTab;

  final ValueChanged<String> onOpenJob;
  final VoidCallback onCreateJob;

  final ValueChanged<ClientJobsTab>? onTabChanged;
  final VoidCallback? onRetry;

  @override
  State<ClientJobsScreen> createState() =>
      _ClientJobsScreenState();
}

class _ClientJobsScreenState
    extends State<ClientJobsScreen> {
  late ClientJobsTab _selectedTab;

  @override
  void initState() {
    super.initState();
    _selectedTab = widget.initialTab;
  }

  @override
  void didUpdateWidget(
    covariant ClientJobsScreen oldWidget,
  ) {
    super.didUpdateWidget(oldWidget);

    if (oldWidget.initialTab != widget.initialTab) {
      _selectedTab = widget.initialTab;
    }
  }

  void _selectTab(ClientJobsTab tab) {
    if (_selectedTab == tab) {
      return;
    }

    setState(() {
      _selectedTab = tab;
    });

    widget.onTabChanged?.call(tab);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: AppColors.background,
      body: SafeArea(
        child: widget.dataAsync.when(
          loading: () => const _ClientJobsLoading(),
          error: (_, __) => _ClientJobsError(
            onRetry: widget.onRetry,
          ),
          data: (data) => _ClientJobsContent(
            data: data,
            selectedTab: _selectedTab,
            onSelectTab: _selectTab,
            onOpenJob: widget.onOpenJob,
            onCreateJob: widget.onCreateJob,
          ),
        ),
      ),
    );
  }
}

class _ClientJobsContent extends StatelessWidget {
  const _ClientJobsContent({
    required this.data,
    required this.selectedTab,
    required this.onSelectTab,
    required this.onOpenJob,
    required this.onCreateJob,
  });

  final ClientJobsViewData data;
  final ClientJobsTab selectedTab;

  final ValueChanged<ClientJobsTab> onSelectTab;
  final ValueChanged<String> onOpenJob;
  final VoidCallback onCreateJob;

  @override
  Widget build(BuildContext context) {
    final jobs = selectedTab == ClientJobsTab.active
        ? data.activeJobs
        : data.historyJobs;

    return Column(
      children: [
        _Header(
          activeTabLabel: data.activeTabLabel,
          historyTabLabel: data.historyTabLabel,
          selectedTab: selectedTab,
          onSelectTab: onSelectTab,
        ),
        Expanded(
          child: jobs.isEmpty
              ? _EmptyState(
                  tab: selectedTab,
                  onCreateJob: onCreateJob,
                )
              : _JobsList(
                  jobs: jobs,
                  tab: selectedTab,
                  onOpenJob: onOpenJob,
                ),
        ),
      ],
    );
  }
}

class _JobsTabs extends StatelessWidget {

    required this.activeTabLabel,

class _TabButton extends StatelessWidget {

class _JobsList extends StatelessWidget {
  const _JobsList({
    required this.jobs,
    required this.tab,
    required this.onOpenJob,
  });

  final List<ClientJobListItemViewData> jobs;
  final ClientJobsTab tab;

  final ValueChanged<String> onOpenJob;

  @override
  Widget build(BuildContext context) {
    return ListView.separated(
      key: PageStorageKey<String>(
        'client_jobs_${tab.name}',
      ),
      padding: const EdgeInsets.fromLTRB(
        AppSpacing.md,
        AppSpacing.xxs,
        AppSpacing.md,
        AppSpacing.lg,
      ),
      itemCount: jobs.length,
      separatorBuilder: (_, __) =>
          const SizedBox(height: AppSpacing.sm),
      itemBuilder: (context, index) {
        final job = jobs[index];

        return AppStaggeredEntrance(
          index: index,
          child: _JobCard(
            job: job,
            historical:
                tab == ClientJobsTab.history,
            onTap: () => onOpenJob(job.jobId),
          ),
        );
      },
    );
  }
}

## Notas de integração

* O wrapper observa os providers e passa `AsyncValue<ClientJobsViewData>`; este ficheiro **não importa `flutter_riverpod` nem usa `ref`**.
* `activeTabLabel` vem pronto da integração. A UI não faz `activeJobs.length` para fabricar a contagem porque o total real pode ser diferente em cenários paginados.
* O badge principal vem sempre do presenter oficial de `JobStatus`: `open` sem propostas → **À espera de proposta / waiting**; `open` com propostas → **N proposta(s) / waiting**; `awaitingConfirmation` → **A aguardar confirmação / info**; `confirmed` → **Confirmado / success**; `completed` → **Concluído / success**; `noResponse` → **Sem resposta / neutral**; `cancelled` → **Cancelado / cancelled**.
* O badge adicional, como **Remarcação pendente**, chega em `secondaryStatusPresentation` e deve vir do presenter de `RescheduleStatus`; nunca é deduzido dentro do card.
* Morada, data e `Flexível` são atributos textuais. Não são estados e por isso não recebem `AppStatusBadge`.
* O `serviceIcon` também vem resolvido de fora; não existe tabela de serviços hardcoded neste ficheiro.
* Cada tab tem um `PageStorageKey` diferente para preservar a respetiva posição de scroll.
* Deliberadamente **não uso `AppFadeThroughSwitcher` para alternar as listas**, porque estas podem atualizar-se em segundo plano e o motion system do projeto alerta para o risco de reset do scroll.
* Loading usa `AppSkeletonShimmer`, nunca spinner.
* O vazio da tab Ativos chama apenas `onCreateJob`; a navegação real continua a cargo do Tech Lead.
